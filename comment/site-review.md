## 총평

**잘 만든 사이트다. 하지만 "좋은 사이트"와 "수상하는 사이트" 사이에 간극이 있다.**

기술 구현(Next.js, Framer Motion, 반응형)은 현대적이고, 정보 구조(비전→전략→현장→성과)는 논리적이며, 콘텐츠 기획(Field 캠퍼스, 통합산단, 연합전공)은 차별화되어 있다. 그러나 **시각적 몰입감, 인터랙션 깊이, 감정적 스토리텔링**에서 수상작 수준에 미달한다.

| 영역 | 점수 | 평가 |
|------|:---:|------|
| 콘텐츠 기획 | 90 | 혁신적 교육 모델을 체계적으로 전달 |
| 정보 구조 | 85 | 명확한 계층, 논리적 흐름 |
| 기술 구현 | 80 | Next.js + Framer Motion, 반응형 |
| 비주얼 디자인 | 70 | 깔끔하지만 임팩트 부족 |
| 인터랙션 | 55 | fade-in만 반복, 스크롤 연출 부재 |
| 접근성 | 50 | alt 텍스트 누락, 포커스 스타일 미정의 |
| 감정적 몰입 | 45 | 사람(학생/교수) 스토리 부재 |

## 강점 — 수상 심사에서 어필할 포인트

### 1. 콘텐츠의 차별성
- **Field 캠퍼스**: "대학 밖 산업 현장이 곧 강의실" — 국내 대학 사이트에서 이런 개념을 이만큼 구체적으로 시각화한 사례가 거의 없음
- **통합산단 수익모델**: 프랜차이징/마켓부스팅/스노우볼링 — 대학이 수익모델을 공개적으로 제시하는 것 자체가 차별화
- **21개 현장 거점 지도**: 추상적 "산학협력"이 아니라 구체적 위치와 분야를 보여줌

### 2. 정보 설계
- 비전→전략→현장→성과 순서가 **설득의 흐름**으로 자연스러움
- 각 페이지가 독립적이면서도 전체적으로 일관된 메시지
- 교과과정표의 전공별 색상 코딩 시스템

### 3. 기술 기반
- Next.js SSR/SSG로 SEO 유리
- SUIT 웹폰트 통일
- 반응형 브레이크포인트(1600px, 1921px) 정교함

## 약점 — 반드시 개선해야 할 사항

### 치명적 (수상 탈락 요인)

#### A. 스크롤 인터랙션 부재
**현재:** 모든 페이지가 동일한 fade-in(`opacity:0→1, y:40→0`) 반복. 스크롤스냅 없음.
**문제:** 심사위원이 스크롤해도 **"아, 또 fade-in이네"** 이상의 인상을 주지 못함.
**해결:** 이전에 정리한 스크롤 전략(scroll-strategy.md) 적용 — Y-Snap, 가로 전환, 영상 확대 등

#### B. 사람이 없다
**현재:** 전략, 숫자, 조직도, 카드. 모든 콘텐츠가 **제도/시스템 중심**.
**문제:** 수상작들은 예외 없이 **사람의 이야기**가 있음. "이 시스템 덕에 내 인생이 바뀌었다"는 감정적 접점이 필요.
**해결:**
- 연합전공 수강생 인터뷰 (영상 또는 카드)
- Field 캠퍼스 현장 사진 (실제 수업 장면)
- JA교원 프로필 카드 (얼굴 + 한마디)
- "2,363명의 수강생" 숫자 옆에 실제 학생 얼굴 1-2명

#### C. 접근성 미달
**현재:**
- 이미지 alt 텍스트 대부분 누락 또는 무의미
- `:focus-visible` 스타일 미정의 (키보드 네비게이션 불가)
- 색상만으로 정보 구분 (색맹 사용자 고려 없음)

**문제:** 웹어워드 심사 항목에 접근성이 포함됨. WCAG 2.1 AA 미달은 감점.
**해결:**
- 모든 `<img>`에 의미 있는 alt 추가
- `:focus-visible` 글로벌 스타일 정의
- 색상 + 텍스트/패턴 병행

---

### 중요 (완성도 차이를 만드는 요소)

#### D. 시각적 리듬 부족
**현재:** 모든 섹션이 "제목 + 설명 + 카드 그리드" 반복. 시각적으로 단조로움.
**해결:**
- 섹션 간 배경색 대비를 더 적극적으로 활용 (현재 대부분 흰색)
- 풀블리드 이미지 섹션 추가 (Field 캠퍼스 현장, 부산 스카이라인 등)
- 숫자 성과 섹션에 배경 영상/이미지 오버레이

#### E. 마이크로인터랙션 부족
**현재:** 카드 hover 효과가 거의 없거나 기본적. 버튼/링크 피드백 약함.
**해결:**
- 카드 hover: 미세한 lift + 그림자 변화
- CTA 버튼: hover 시 배경색 전환 + scale 미세 변화
- 탭 전환: 콘텐츠 교체 시 slide/crossfade 트랜지션

#### F. 데이터 시각화 미흡
**현재:** 특허 분석 막대 차트 외에는 숫자를 텍스트로만 표현.
**해결:**
- 통합산단 매출 918억: 연도별 성장 추이 차트
- 유학생 3,898명: 국가별 비율 도넛 차트
- 브랜치 25개→100개: 타임라인 프로그레스 바

---

### 보완 (있으면 좋은 것)

#### G. 로딩 경험
- 스켈레톤 로더 또는 프로그레스 바 추가
- 이미지 lazy loading + blur placeholder

#### H. 모바일 경험 강화
- 데스크톱/모바일 배너가 별도 컴포넌트로 분리됨 — 코드 중복
- 교과과정표의 테이블이 모바일에서 가독성 저하 우려
- 카드 캐러셀 스와이프 제스처 피드백 강화

#### I. SEO/메타데이터
- Open Graph 이미지/설명 최적화 확인 필요
- 각 페이지별 고유한 title/description

## 수상작 대비 포지셔닝

**현재 위치:** 기술적으로 견고하고 콘텐츠가 차별화된 "좋은 대학 사이트"
**목표 위치:** 인터랙션과 스토리텔링으로 감동까지 주는 "수상하는 사이트"

간극을 메우는 핵심: **스크롤 연출(이성적 전달) + 사람 이야기(감정적 몰입)**

이 두 축이 보완되면 대학/교육 카테고리에서 충분히 경쟁력 있다.
